# 🌱 PANGANIN — Platform Gen-Z untuk Kedaulatan & Inovasi Pangan Lokal

> **PANGANIN** adalah aplikasi web interaktif berbasis modern web stack yang dirancang untuk mengkampanyekan kesadaran pangan lokal, mengurangi jejak karbon rantai pasok makanan, serta mempromosikan UMKM pangan Nusantara dengan gaya antarmuka yang ramah Gen-Z.

---

## 🚀 Fitur Utama

1. **Dashboard Utama**: Pusat navigasi cepat dengan ringkasan metrik dampak, misi harian, dan akses langsung ke seluruh fitur platform.
2. **Kenal Lagi Bahan Lokal**: Ensiklopedia digital yang mengulas kekayaan bahan pangan alternatif lokal (seperti Tepung Mocaf Temanggung, Gula Semut Aren, dan Daun Kelor) lengkap dengan analisis jejak karbonnya.
3. **Local Food Makeover**: Wadah resep *fusion* modern untuk mengubah bahan tradisional menjadi hidangan ala kafe, lengkap dengan fitur interaktif **Simpan Resep Favorit (*Bookmark*)** berbasis `localStorage`.
4. **Smart Choice (Panduan Belanja Cerdas)**: Tips dan trik cerdas dalam memilih produk pangan lokal yang sehat, berkualitas, dan berkelanjutan.
5. **Kalkulator Jejak Karbon Pangan**: Simulasi interaktif bagi pengguna untuk menghitung estimasi emisi karbon harian berdasarkan pola konsumsi mereka dan melihat lencana apresiasi (*badge*).
6. **Impact Dashboard**: Visualisasi data statistik dan dampak positif gerakan konsumsi pangan lokal terhadap lingkungan dan kesejahteraan petani.

---

## 🛠️ Teknologi yang Digunakan

* **Framework**: React (dengan Vite)
* **Styling**: Tailwind CSS (Desain modern, responsif, dan elegan)
* **Icons**: Lucide React
* **Routing**: React Router DOM
* **Storage**: Browser LocalStorage (untuk manajemen data interaktif lokal)
